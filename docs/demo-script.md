# Two-minute demo

1. Open the wall. The cards are screenshots already on the machine, plus the synthetic golden set if you have just run the eval.
2. Press `/` and type `nginx`. The error card moves to the front. The line that matched is outlined. Click Copy text. The command is not executed.
3. Clear the box and type `maple street`. The address card comes forward. Click Open in Maps only if you want the map. The click is the action.
4. Open Ask your shelf. Ask `what is the password`. The reply refuses. It cites the screenshot and does not repeat a password from the image.
5. If someone asks what you would charge for later: the index is the valuable thing. Sync to a phone, and a shared shelf for a team, are the paid steps. The laptop app stays local. Nothing in this version bills anyone.

The numbers behind the demo are in `eval/reports/ablation.json`.
